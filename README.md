# MitsuDrive

Социальная сеть для автомобилистов с функциями мессенджера.

## Архитектура

### Модули
- **core/** — базовые модули (UI, сеть, БД, синхронизация)
- **features/** — бизнес-модули (лента, чаты, карта, гараж, SOS)

### Технологии
- **Kotlin** + **Coroutines** + **Flow**
- **Jetpack Compose** — UI
- **Hilt** — DI
- **Room** — локальная БД
- **OkHttp** — HTTP + WebSocket
- **Google Maps SDK** — карта
- **FCM** — push-уведомления
